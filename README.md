# Learning Tracker

A single-file learning outcome tracker built with vanilla HTML/CSS/JS. No build step, no dependencies, no backend.

## Features
- 4 pre-loaded subjects — Mathematics, Computational Thinking, Statistics, Python
- Per-outcome 4-tab panel — Details, Mastery, Recall, Mistakes
- Mastery stars + Difficulty Score (Attempts × (5 − Stars))
- Week CRUD with ⋯ context menu — Edit, Add Outcome, Delete
- Need Help / To Review queue system
- Save/Load progress as JSON
- Installable as a PWA (Chrome, Edge, Android, iOS)

## Usage
Open `index.html` directly in a browser — or visit the live version:
**[username.github.io/learning-tracker](https://Krishna-Yelnure.github.io/learning-tracker)**

For PWA install (adds to home screen / desktop), open the live link in Chrome or Edge.
