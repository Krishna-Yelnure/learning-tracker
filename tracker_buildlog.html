v28 PWA — manifest, service worker, install button, LT icons math_course_tracker_28.html
  • LT monogram icons — generated as inline SVG at runtime (32px favicon, 192px and 512px app icons); dark background with serif lettermark; set as favicon, apple-touch-icon, and manifest icons via data URIs — no external files
  • Web App Manifest — built as JSON and injected as data:application/manifest+json link; covers name, short_name, display: standalone, theme/background colours, orientation, both icon sizes
  • Service Worker via Blob URL — SW code built as string array, converted to Blob URL and registered; cache-first strategy caches app shell on install, falls back gracefully on file://
  • Install button in bottom bar — appears only when relevant; Chrome/Android: shows on beforeinstallprompt, triggers native prompt; iOS Safari: always shown (no install event), shows "Tap Share → Add to Home Screen" toast; hides on appinstalled
  • Entire PWA init wrapped in try/catch — PWA failure is completely silent; app remains fully functional if any PWA API is blocked (sandboxes, file://, etc.)
  • Bug fix: rogue -e in script — echo -e wrote literal -e token into the JS block causing ReferenceError: e is not defined on every page load; removed
  • Replaced deprecated unescape() — base64 encoding now uses encodeURIComponent + regex byte-walk, works in all strict sandboxes

  • Real SVG icon files — icon-192.svg and icon-512.svg added to repo; same LT monogram design as the runtime-generated versions, now served as static files referenced by manifest

Brainstorm
Full feature roadmap
Design principle: Every feature must pass — "Does this make a student open the app more often and study more effectively?" Features that create dashboards to admire instead of tools to use get cut.
A
Habit Layer — make students come back daily
Estimated rating after: 9.5
🔥
Daily Streak Counter Consecutive days with any interaction. Visible in header. Pomodoro session counts toward streak. Low effort, high habit impact.
⏳
Exam Date + Countdown per Subject Set exam date → header shows "Maths exam in 14 days — 68% complete". Urgency score: outcomes/day needed. Turns red when urgent.
🍅
Pomodoro Timer — floating bottom-right widget 25 min study / 5 min break. Auto-links to current subject + week. Session stored: {subject, week, duration, outcomes_completed, timestamp}. After 4 sessions → 15 min long break. Unlocks study hours stats for free.
B
Intelligence Layer — tell students what to do next
Estimated rating after: 9.7
🔁
Spaced Repetition Scheduler Highest learning science impact. Rating → auto-schedule review: 1★=1day, 3★=3days, 5★=14days. "Due Today" queue at top. Re-rating updates next review date.
📈
Confidence Trend Sparklines Each re-rating stored (not overwritten). Small sparkline per outcome: ★☆☆→★★☆→★★★. Week-level average confidence over time. Progress made visible.
📋
Weekly Review (auto-generated) Sunday modal: outcomes completed, reviews missed, hardest outcomes this week, next week focus. One-click tag hard outcomes. Not manual — auto-generated from existing data.
C
Power Layer — genuinely unforgettable
Estimated rating after: 9.9
🤖
AI Recall Checker (Claude API in Recall tab) After free-write recall, click "Check my recall" → Claude compares to outcome text and gives gentle feedback. No grade — just "Good, you missed: edge case when n=0". Unique differentiator. No other study tracker has this.
📊
Study Analytics Dashboard Total hours, sessions per subject, confidence trends, outcomes/hour, best study times. Built from Pomodoro + spaced repetition data already being collected.
